# 도시의 한 사람으로 태어나 — 개인용 수정본

이 저장소는 제공받은 배포 파일을 바탕으로 한 개인용 수정 실험본입니다.

## GitHub Pages로 열기
1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 **내용물 전체**를 저장소 최상위(root)에 업로드합니다. `index.html`이 최상위에 있어야 합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치의 `/(root)`를 선택한 뒤 저장합니다.
5. 몇 분 후 표시되는 Pages 주소로 접속합니다.

## 이벤트 편집
- Pages 주소 뒤에 `/editor.html`을 붙이면 편집기를 열 수 있습니다.
- 편집기에서 이벤트를 작성하고 `custom-events.js`를 내보낸 다음, 저장소의 기존 `custom-events.js`를 교체합니다.
- 변경 사항을 커밋하면 Pages가 다시 배포됩니다.

## 중요
- GitHub Pages에 게시된 저장소와 사이트는 기본적으로 공개될 수 있습니다. 완전히 비공개로만 쓰려면 공개 Pages 배포 대신 로컬 실행 또는 접근 제한이 가능한 호스팅이 필요합니다.
- 이 편집본은 원본 사이트의 서버 기능을 복제하지 않습니다.
- 배포용 JS 번들은 압축되어 있습니다. 이벤트를 추가하는 연결은 포함되어 있으나, 원본 이벤트 편집/삭제 기능은 아직 구현되지 않았습니다.
- 원본 프로젝트의 저작권 및 이용 조건을 확인하고, 개인적인 용도로 사용하세요.
